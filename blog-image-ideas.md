## AI 이미지 생성 — 공통 가이드라인

### 색상 팔레트 (사이트와 일치)
```
Primary Red:  #C41E3A
White:        #FFFFFF
Dark BG:      #1A1A2E  (다크 배경용)
Gold Accent:  #FFD700  (브라질, 하이라이트)
```

### 항상 포함할 프롬프트 요소
```
[장면 설명], photorealistic, bright natural lighting, 
high quality product photography, 16:9 aspect ratio, 
no text overlay, clean composition, vibrant colors
```

### 피해야 할 프롬프트 요소
```
- 실제 선수 이름 (초상권 문제)
- 공식 FIFA/Panini 로고 (상표권)
- 특정 팀 공식 유니폼 (라이선스)
- 실제 경기장 상표
```

## 이미지 최적화 스펙

```
형식:   .webp 권장 (PNG도 가능, JPEG는 hero에 부적합)
크기:   1200×750px (16:10)
용량:   200KB 이하 권장 (Next.js Image 컴포넌트가 최적화하지만 원본도 관리)
네이밍: kebab-case, 설명적으로 (SEO alt 텍스트와 연결됨)
```

```bash
# ImageMagick으로 리사이즈 + webp 변환 (Codex에게 시킬 수 있는 명령어)
magick input.jpg -resize 1200x750^ -gravity center -extent 1200x750 output.webp
```
